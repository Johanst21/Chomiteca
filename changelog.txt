[B]v1.8.2 (June 01, 2025):[/B]
- Critical Library Integration Fixes: Addressed critical errors, including timeouts (Timeout was reached(28)) and playback failures, when launching content from the Kodi library (via .strm files), especially when   managed by addons like Jellyfin.
     - Resolved an InvalidURL error by implementing robust URL encoding for paths passed from external sources, which often contain unescaped characters like spaces.
     - Rearchitected the external playback flow (play_from_outside) to resolve and immediately pass the final, temporary playback URL directly to Kodi's player using setResolvedUrl. This crucial change prevents the link from expiring due to delays introduced by intermediary addons, which was identified as the root cause of the frequent timeout errors.
- Proactive Connection Warm-up: Implemented a new start-up routine (warm_up_connection) that performs a lightweight, proactive network request upon addon initialization. This "warms up" the network connection to Chomikuj's servers, drastically reducing the "cold start" latency and making the first playback initiated in a session feel as responsive as subsequent ones.
- UI & Visual Enhancements: Minor adjustments have been made to font colors and other visual elements throughout the addon's interface for improved readability and a more polished, consistent user experience.

[B]v1.8.1 (May 28, 2025):[/B]
- Login and Account Management Refactoring: Login logic and the availability of account-dependent features are now centrally managed via the main menu's "Manage Accounts" options. Global user variables (username_setting_global_ref, usernameURL_global_ref) are dynamically updated when selecting/changing the active account or upon addon startup. Improved workflow for adding new accounts and setting them as active.
- Playback Start-Time Optimization: Addressed an issue causing significant delays when initiating playback, especially when launched from integrations like Jellyfin. Optimization focuses on ensuring Kodi processes the addon-resolved URL more efficiently, reducing latency between URL resolution and the actual stream startup. (Note: External factors like Kodi library scans or Chomikuj server speed may still have an impact.)
- Enhanced .strm File Generation: Fixed an issue that prevented the creation of .strm files within subfolders during the first run of the "Generate .strm files for library" feature. Improved the robustness of creating nested directories on the local filesystem using xbmcvfs, including additional checks and fallbacks to ensure the folder structure is correctly created before generating .strm files. Resolved an `AttributeError` related to `DialogProgressBG.iscanceled()` and unified user cancellation detection via `xbmc.Monitor().abortRequested()`. Verified and corrected the definition order of helper functions to prevent `NameError` during .strm generation.
- Full Spanish Translation: User interface and notification translations to Spanish have been reviewed and completed, utilizing Kodi's localized string system.
- Minor Bug Fixes and General Improvements: Fixed several minor bugs reported and found during development. Improved pagination logic for within-account searches. Enhanced logging for easier debugging. Refined the handling of `ChomikName` and `__RequestVerificationToken` retrieval in different search scenarios. Adjustments in `addDir` and `addCont` functions for more consistent name and URL handling.
